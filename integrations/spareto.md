# Integração — Spareto

Fonte prioritária de aplicação, equivalências e dados técnicos. Referência: SOUL.md, seção 8.1.

## Status

✅ Consulta via web (sem API formal). URL base: https://spareto.com

## Uso

- Buscar pelo código OEM, código do fabricante ou equivalente.
- Extrair: produto, marca, aplicação, códigos equivalentes, dados técnicos e imagens (quando disponíveis).
- Registrar cada consulta em `logs/consultas-spareto.md` com código pesquisado, resultado, link e data.

## Nível de confiança

**Alta confiança** quando a aplicação estiver clara (SOUL.md, seção 25). Em ambiguidade, confirmar no catálogo oficial do fabricante. Em conflito, o catálogo oficial prevalece.
