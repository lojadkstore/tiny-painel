# Método — Consultar Spareto

Fonte prioritária para aplicação e equivalências. Referência: SOUL.md, seção 8.1.

## Usar o Spareto para

- Aplicação
- Equivalências
- Códigos relacionados
- Tipo de peça
- Marca
- Imagens, quando disponíveis
- Dados técnicos

## Registrar em toda consulta

- Código pesquisado
- Produto encontrado
- Marca
- Aplicação
- Códigos equivalentes
- Link da página
- Dados técnicos
- Data da consulta

Registro em `logs/consultas-spareto.md`.

## Fallback

Se o Spareto não retornar aplicação suficiente ou houver ambiguidade, seguir para o catálogo oficial do fabricante (`consultar-catalogo-fabricante.md`). Em conflito entre fontes, o catálogo oficial prevalece (SOUL.md, seção 26).
