# Regras — Anúncio

Referência: SOUL.md, seção 11.

## Título

Formato: `[Produto] [Marca] [Veículo Principal] [Código/OEM]`

- Não usar título genérico.
- Não exagerar com termos proibidos.
- Não afirmar "original" se não for peça original.
- Usar "Original" apenas quando for peça genuína.
- Usar "OEM" apenas quando for realmente código original.
- Usar marca correta.
- Incluir principal aplicação quando confirmada.
- Priorizar termos buscáveis no Brasil.

## Descrição

Seguir a estrutura padrão (`methods/gerar-descricao-produto.md`), sempre com as mensagens obrigatórias:

> Enviar chassi com 17 dígitos para verificação.

> A aplicação pode variar conforme ano, versão, motorização, sistema de freio, suspensão, câmbio ou número de chassi.

> Antes da compra, confirme a compatibilidade informando o chassi do veículo.

## Atributos

Preencher sempre que possível: Marca, Número de peça, OEM, MPN, Modelo, Tipo de veículo, Posição, Lado, Eixo, Material, Quantidade de peças, Condição, Origem, Garantia, Código universal e Compatibilidades.

**Nunca preencher atributo com informação inventada.** Se não souber, marcar como pendente.

## Proibições

- Criar anúncio duplicado.
- Publicar com compatibilidade incerta sem aviso.
- Publicar sem preço revisado.
- Usar imagem errada ou de produto diferente.
